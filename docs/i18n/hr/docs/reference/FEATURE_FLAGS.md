> Preklopnici tijekom izvođenja koji mijenjaju ponašanje OmniRoutea **bez ponovnog postavljanja**.
> Svaka ovdje navedena zastavica definirana je u
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — jedinstvenom izvoru istine. Nadzorna ploča i REST API čitaju iz
> te datoteke, pa je tablica u nastavku generirana tako da joj odgovara 1:1.

---

## Što su zastavice značajki

Zastavica značajke imenovani je preklopnik (Booleova vrijednost ili enumeracija) čija se vrijednost može promijeniti
tijekom izvođenja i trajno pohraniti u bazi podataka, bez potrebe za ponovnim postavljanjem procesa. Svaka
zastavica opisana je objektom `FeatureFlagDefinition` s poljima `key`, `label`,
`description`, `category`, `defaultValue`, `type` i naznakom `requiresRestart`.

### Redoslijed određivanja vrijednosti

**Efektivnu vrijednost** zastavice određuje
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) prema sljedećem
redoslijedu prvenstva (najviši pobjeđuje):

1. **Nadjačavanje iz baze podataka** — vrijednost pohranjena u tablici `key_value` unutar
   prostora imena `feature_flags` (postavljena putem nadzorne ploče ili REST API-ja).
2. **Varijabla okruženja** — `process.env[<KEY>]`, ako je postavljena i nije prazna.
3. **Zadana vrijednost definicije** — `defaultValue` iz `featureFlagDefinitions.ts`.

Booleova zastavica smatra se **omogućenom** kada je njezina efektivna vrijednost `"true"`,
`"1"` ili `"yes"` (pogledajte `isFeatureFlagEnabled()`).

> [!NOTE]
> Većina zastavica također ima odgovarajuću varijablu okruženja **istog naziva**
> dokumentiranu u datoteci [`ENVIRONMENT.md`](./ENVIRONMENT.md). Nadjačavanje zastavice iz baze podataka
> ima prednost nad tom varijablom okruženja. Zastavica s
> `requiresRestart: true` odmah se trajno pohranjuje, ali se ponovno učitava samo pri
> pokretanju procesa — njezino prebacivanje prikazuje natpis **"Ponovno pokreni poslužitelj"** na nadzornoj ploči.

## Prebacivanje zastavica

### Nadzorna ploča

Idite na **Nadzorna ploča → Postavke → Zastavice značajki**
(`/dashboard/settings/feature-flags`). Mreža
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
podržava:

- **Pretraživanje** prema ključu ili opisu te **filtriranje** prema kategoriji (uz sintetički prikaz
  **Zahtijeva ponovno pokretanje**).
- **Prekidač** za Booleove zastavice i **padajući izbornik** za enum zastavice
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- **Oznaku izvora** za svaku zastavicu — `DB`, `ENV` ili `DEF` — koja prikazuje odakle
  dolazi efektivna vrijednost.
- Gumb **Poništi** (prikazan samo za zastavice čiji je izvor `DB`) za uklanjanje nadjačavanja
  i gumb **Poništi sva nadjačavanja** pri dnu.
- Natpis **Ponovno pokreni poslužitelj** kada se promijeni zastavica `requiresRestart`.

### REST API

Sve operacije prolaze kroz jednu rutu:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Svaka metoda zahtijeva autentificiranu sesiju nadzorne ploče (u suprotnom vraća `401`).

#### `GET /api/settings/feature-flags`

Vraća svaku zastavicu s njezinom efektivnom vrijednošću, izvorom i sažetkom.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... svih 72 zastavica
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Postavlja ili uklanja pojedinačno nadjačavanje. Tijelo: `{ key: string; value?: string }`.
Izostavljanje vrijednosti `value` uklanja nadjačavanje (vraćajući vrijednost iz okruženja / zadanu vrijednost).

```bash
# Postavljanje DB nadjačavanja
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Uklanjanje nadjačavanja (bez "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Odgovor vraća novu vrijednost `effectiveValue`/`source`, prethodnu vrijednost `previousValue`/
`previousSource` i `requiresRestart`. Nepoznati ključevi i enum
vrijednosti izvan dopuštenog raspona odbijaju se kodom `400`.

#### `DELETE /api/settings/feature-flags`

Odjednom briše **sva** DB nadjačavanja, vraćajući svaku zastavicu na njezinu vrijednost
iz okruženja / zadanu vrijednost. Vraća `{ cleared: <count>, message: "..." }`.

> [!NOTE]
> Zastavice s `requiresRestart: true` stupaju na snagu tek nakon ponovnog učitavanja procesa.
> Tijek ponovnog pokretanja na nadzornoj ploči poziva `POST /api/restart`, a zatim periodički provjerava
> `GET /api/health/ping` dok se poslužitelj ponovno ne pokrene.

## Rezervni mehanizam za prekoračenje proračuna u hitnim slučajevima

`OMNIROUTE_EMERGENCY_FALLBACK` (kategorija `runtime`, zadano `true`) upravlja
rezervnim besplatnim putem za hitne slučajeve u
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Kada je omogućen, zahtjevi koji iscrpe svoj proračun usmjeravaju se prema besplatnom rezervnom
pružatelju usluge/modelu umjesto da odmah ne uspiju. Postavite ga na `false` (ili `0`) — putem
prekidača na nadzornoj ploči, DB nadjačavanja ili varijable okruženja
`OMNIROUTE_EMERGENCY_FALLBACK` — kako biste onemogućili to ponašanje i dopustili da zahtjevi
koji su iscrpili proračun ne uspiju. (Prikazano kao prekidač na nadzornoj ploči u PR-ovima #3741 / #3752.)
